# OKF 与医疗证据项目的适配评估

核验日期：2026-11-17。用户提出项目可以使用 OKF；本文暂按 GoogleCloudPlatform 的 Open Knowledge Format 理解。该建议尚未变成迁移决定，当前没有 OKF 导出、读取工具或相关实测结果，不改动检索基线及原始医学数据。

**用户最新决定（2026-11-17）：先按原计划推进，待完整数据扩充并固定版本后，再做 OKF 对照。** 下述方案只保留为届时的候选设计；当前不导出 OKF 目录、不增加读取工具，也不将 OKF 作为 CT 基线或既有检索改进的前置任务。

## 已核实的外部能力

- [官方仓库](https://github.com/GoogleCloudPlatform/open-knowledge-format)与[规范](https://github.com/GoogleCloudPlatform/open-knowledge-format/blob/main/SPEC.md)：当前展示 v0.2，以带 YAML frontmatter 的 Markdown 文件构成知识目录；支持来源、生成者、核验事件、生命周期、文档链接和目录导航。不规定检索基础设施或医学领域模式。
- 规范的 type 是始终必需的字段；临床任务需要的地区、人群、适用场景、页码及审核范围并非规范自动提供。sources、generated、verified、status、stale_after 可以表达部分治理信息，但字段存在本身不能证明内容正确。
- 官方参考 Agent 主要展示 BigQuery 元数据及网页补充，示例涉及 GA4、Stack Overflow、Bitcoin 等；所查 README 未提供本项目需要的医学适用性验证或临床评测结果，不能直接当成现成医疗 Agent。
- [仓库许可证](https://github.com/GoogleCloudPlatform/open-knowledge-format/blob/main/LICENSE.md)为 Apache-2.0。医学原文的采集、存储和再分发条件仍按原来源管理，不能因转成 OKF 而改变。
- 相关预印本 [Knowledge-as-Skill](https://arxiv.org/abs/2609.25991)讨论知识的可发现性与导航，在 WixQA 上做了初步评估，作者明确说明跨工作设置不同、比较不受控。它不是本项目的医学有效性或性能提升证据。

## 本项目已有内容与可能增益

当前 data/v2/sources.json 已有 6 条来源记录，包含版本、日期、类型、使用条件及原始快照指纹；evidence.jsonl 已有 238 条可检索证据，带 source_id、locator、review_status 等。不能将这些已有能力改称 OKF 带来的新贡献。

可能值得引入的部分是可阅读、可审查的来源目录：按文件解释证据类型和适用边界，让 Agent 按目录查找来源，再读取带原始位置的证据。临床扩展字段需要单独定义并注明未确认项，尤其是地区、人群、检查目的、产品身份与审核范围；不以模型推断填成已核验事实。

例如报告明确属于筛查时，可以把筛查相关来源作为检索候选的优先范围；检查目的未知时则保留候选并追问。目录只能支持选择与导航，结论仍需引用原文。该策略是待实现的路由与适用性核验，不是 OKF 文件格式自带的推理能力。

## 完整数据扩充后再评估的试验方案

1. 先按原路线完成开发和完整数据扩充，随后固定对照所用的语料与题目版本。当前 6 份来源的小库不提前开展 OKF 试验。
2. 届时从固定版本的来源元数据自动导出只读 OKF 目录，并链接到既有证据 ID；不把全部证据人工改写成 Markdown，不同时手工维护两份真值。导出器未来可由助手负责数据辅助，检索和 Agent 工具的核心仍由用户实现。
3. 检查导出前后来源 ID、原始链接、版本、使用条件和证据关联一致；未确认内容明确保留。当前来源核验日期不能自动映射成每条医学结论的 verified。
4. 在同一固定数据版本上，再实现按需读取目录／来源及原始证据的工具，运行关闭／开启目录路由对照，观察指南选择、条件缺失处理、引用支持与成本。

若要把性能变化归因于 OKF，而非目录新增的信息或路由算法，还需同信息的 JSON 目录对照。无需预先承诺这种文件格式优于现有 JSON；可读性和维护便利也可以是采用理由。

## 不可替代的后续工作

OKF 不增加医学文献数量，不解决 PDF 表格恢复或 OCR 错误，不自动判定指南适用性，也不免除重新编码和评测。human-reviewed 表示有人的核验事件，不等于医生审核或医学证据级别；需另记审核者角色及审核范围。stale_after 是需复查时间，不能替代指南是否被新版取代的查证；本项目未经审核的内容应显式保留草稿及审核状态。

MIRAGE 全量 7,663 题及广泛医学语料的硬目标不变。OKF 目录不读取或收录基准答案，也不能用逐题答案式概念替代独立外部证据。
