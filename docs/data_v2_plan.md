**NCI 内容在项目中的角色**

NCI PDQ 页面明确说明其不提供正式临床指南或医疗决策推荐。因此将其标记为 `evidence_summary`，用于筛查背景、证据解释和来源类型区分，不能代替 ACR、Fleischner 等原始指南的适用条款。[页面说明](https://www.cancer.gov/types/lung/hp/lung-screening-pdq)

这一步首先把可复用正文的采集链路跑通。正式指南资料继续保留其来源身份与待核验事项，不为凑数量把不同层级的材料统一称为指南。

**多格式解析的统一边界**

统一的是解析结果和下游接口，文件读取方式按格式分别处理。采集阶段共用下载和字节保存逻辑；结合响应 Content-Type 与文件内容特征识别格式，使用对应扩展名，不把重命名视为格式转换。无法确认类型时先保留检查状态。

| 原始格式 | 解析方式 | 需要保留的定位 |
| --- | --- | --- |
| HTML | 提取正文、章节标题及原有锚点，过滤导航等内容 | 章节路径、实际存在的锚点，以及本地段落标识 |
| 有文本层的 PDF | 按页提取文字，核对表格关系和阅读顺序 | 从 1 开始的文件页码，必要时保留区域坐标 |
| 扫描 PDF 或报告图片 | 后续通过 OCR 或视觉解析提取文字并核对关键字段 | 页码及图像区域坐标 |

v2 计划让不同解析器输出同类证据块，至少包含 id、source_id、text 和结构化 locator。locator 内保留格式对应的定位字段，不为 HTML 编造页码，不为没有锚点的段落编造网页锚点。原始文件路径、内容指纹及最终 URL 保存在采集记录中，用于回查。现有 v1 文件不据此直接迁移或覆盖。

整理成证据块之后，分段、向量化、检索和回答可以共用流程；引用展示仍根据定位类型生成页码或章节链接。文本提取完成不等于条款含义、适用条件和表格关系已经核验。

当前已验证两个 NCI 单章和 PDF 逐页读取；助手另按用户授权实现第二页编号注释分段，保存 16 条带来源位置的记录并通过 6 项检查。自动全页结构解析、统一输出和扫描件解析尚未实现。2026-11-16 的 [PDF 对照](pdf_extraction_comparison.md) 表明：第 0 类三行在两种模式中均可由人工对应，layout 没有修复单位编码或显式输出合并单元格。继续保留普通逐页文本作中间输入，表格结构需另行恢复。下一步统一核对过的候选证据输出，接回 RAG；编号分段不再作为待做任务。

**目标与覆盖**

第一版以约 100–300 个有定位的证据单元、40–60 道文本题作为工作量规划，实际数量取决于可用条款和自然段落。题目数之外还记录病例或模板家族数，同一病例的改写不重复计为独立样本。

| 覆盖维度 | 需要保留的条件区别 | 主要观察 |
| --- | --- | --- |
| 当前任务 | 选择框架、解释条款、资格核对、具体分类 | 是否只追问阻碍当前任务的信息 |
| 检查目的 | 筛查、偶发发现、未说明 | 指南选择和具体澄清 |
| 人群条件 | 年龄、已知原发肿瘤、免疫抑制等 | 条款适用范围是否保留 |
| 检查方式 | 胸部 CT、胸片、部分胸部成像 | 是否混用不同检查场景的来源 |
| 比较影像状态 | 正在调取、已有可用影像、未说明 | 是否把某个触发状态扩大成所有情况 |
| 数量与形态 | 单发、多发，以及来源已明确覆盖的类型 | 是否把只适用某类情况的条款泛化 |
| 报告事实 | 数字、单位、否定词和左右侧 | 是否完整保留原始事实 |
| 来源与证据充分性 | 指南、推荐声明、证据综述；有无目标条款 | 是否把背景研究或综述当成具体推荐 |

对条件成对变化的题目，问题应限定到证据实际支持的命题。例如核对“正在调取既往影像”这一条原因是否得到支持，不能只依据单张卡直接推断整个病例的最终类别。

每道题的证据与标注需回到来源核对。先形成候选，再校对事实、适用条件和定位，保留人工初标状态；没有原始依据时不先生成一个肯定的标准答案。

**划分规则**
