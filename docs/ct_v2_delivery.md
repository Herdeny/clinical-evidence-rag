# CT v2 批量数据交付记录

日期：2026-11-16。用户要求“扩数据一次性搞完”，本轮授权扩大到整批数据准备、统一表示、质量检查及题目初标；检索、生成、评分和 Agent 核心代码仍留给用户实现。

实际结果为 **6 份来源快照、241 条候选、238 条本地检索输入、48 道合成题、24 个场景家族**。开发／留出为 32／16 题，按家族为 16／8。候选和检索输入单独统计，原 v1 的 15 张转述卡不直接加入本批计数。

本轮实现 [ct_data_pipeline.py](../scripts/data/ct_data_pipeline.py)、[题目蓝本](../scripts/data/ct_case_blueprints.py) 和 [来源与划分验证](../scripts/data/validate_ct_data.py)。脚本通过格式适配生成共同证据结构，NCI 与 USPSTF 正文批量处理，ACR 表格保留场景与行列关系，PDF 保留完整注释及原页位置。

12 项检查通过，涵盖原始指纹、HTML 原文元素与锚点、文本切片重建、PDF 页文本、适用场景和表格处理栏对应、来源类型、单位与等待状态、长度、隔离记录和家族划分。当前正文最长 434 tokens，使用本地 BGE tokenizer 检查，没有静默截断。独立 [数据验证报告](../results/ct_v2_validation.json) 保存全部数据文件指纹及实际统计。

质量排除包括：Fleischner 无本地全文、Lung-RADS 第一页复杂表格未自动恢复、注释 6 原文数值表达待核对，以及两条不在本轮范围的多癌种检测记录。排除内容保留原因，不填入编造的原文或自动更正数值。

48 题由助手生成并逐条关联现有来源，状态为 AI 初标草稿，未经独立人工或医生复核。验证通过表示引用位置和划分可用，不表示医学标准答案已获得临床验证。算法未运行，未新增 Recall、引用支持或澄清指标成绩。

后续直接使用 [数据说明](../data/v2/DATA_CARD.md) 中的文件接口进行基线复测：用户编写新语料的向量编码、检索与证据组评分，固定数据和题目后再接 BM25／RRF 等改进。本轮不再要求用户逐条拼装这批候选或重写数据准备脚本。公开发布时按 [来源使用范围](../data/v2/USAGE.md) 处理，不能将整个本地语料称为已获开放授权。
