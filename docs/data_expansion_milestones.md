**本轮交付已完成：** 新增132题，与原48题合成120开发／60留出、30规则家族，每族6个条件变体；原24家族保留划分。文件位于data/evaluation/ct_v3，详见[数据说明与复核步骤](../data/evaluation/ct_v3/DATA_CARD.md)。4项构建器检查和[独立结构复验](../results/ct_eval_v3_validation.json)通过，79条参考可回查；主库、完整文档向量及旧成绩未变。新增的是评测覆盖，未新增来源或正文编码；所有标签仍待独立人工复核，当前0题完成，并无新RRF成绩。

职责更正：用户不必先填写review.dev.csv才能继续项目。助手继续负责来源回查和数据核验，独立人工／医生复核状态照实保留。下一步在固定120道开发草稿上做Dense／BM25／RRF探索性对照，明确披露AI初标，不将分数当作临床准确率；长任务由用户在可见终端执行，旧成绩和完整向量复用。正式结论另行核查标签质量，发现标签问题须另记版本。留出不参与调试。180题覆盖30规则家族，不是180个独立病例。以下“尚未新增题”及强制先由用户复核的安排均为此前状态。

本日功能进度：RRF融合／查询编排及三方法入口已通过相应小样本检查；保存辅助已适配用户的方法层配置，当前转入评测覆盖清单、扩题和原文标签回查。尚未新增题目或完成新标签复核，也未运行真实全库RRF对照。

医学v3主语料与完整Dense缓存已经固定，BM25和Dense在原32题上完成实测。用户于11月20日质疑开发题数量：32题来自16家族，每族2题，且仍为AI初标；一题需求组覆盖从0到1可改变宏平均3.125个百分点，不能凭这个量级的差距下稳定的泛化结论。

当前顺序为：用户完成RRF纯融合函数和手工验收；正式方法对照之前，先补充CT专项评测的场景覆盖与标签核对，冻结新版题集；再在同一新版题集上评测Dense、BM25和RRF。近期建设预算建议为开发100–150题、家族隔离留出50–80题，具体由可回查证据与独立条件组合决定，不是保证统计充分的门槛。当前尚未生成新增题，也未完成相关复核。

扩题前先建立来源条款／场景／预期行为覆盖清单；每题确认必需证据组、允许替代的支持材料、必要缺项及原文位置。扩库后的潜在等价证据遗漏属于待检查问题，不能直接把所有未命中旧gold的结果判为医学错误，也不能依据某一路结果倒改旧标签。旧32／16和成绩保留，新评测另设版本；按家族隔离开发／留出，文本、PDF和图片变体关联同一基础病例。

这轮扩的是评测题，原evidence.jsonl、模型及文档编码配置保持不变，复用783,847行完整向量；需要重新检索和评分，但无需重新文档编码。用药／跨来源／多模态仍需另建专项题；MIRAGE7663为独立最终外部测试，不能转作反复调参的开发题。以下2026-11-18的“扩库”记录指语料扩充历史，两者分别统计。

**最新执行安排：先批量扩充并固定主要检索语料版本，再做向量／BM25／RRF 的正式对照。** 用户指出扩库后仍需重复构建和评测；此前“先在 CT 小库做完 BM25／RRF 再扩”的顺序会产生额外实验。当前纯向量结果已完成，保留为回归基线；不要求继续在小库精调或完成 BM25／RRF 正式实验。已准备的依赖、保存辅助和检索接口继续复用。

**本轮实际交付：医学主语料 v3 已冻结并通过独立完整性校验。** 9,836 篇 PMC 论文／480,538 片段，998 份 DailyMed 产品说明书／303,071 片段，另保留 CT 的 6 来源／238 片段，总计 **10,840 来源、783,847 片段、594,483 条不同正文**。语料约 1.239 GiB，全部片段最高 480 BGE tokens，来源位置与旧 CT 指纹检查通过。见 [数据说明](../data/v3/DATA_CARD.md)、[实际清单](../data/v3/corpus_manifest.json)、[独立验证](../results/medical_corpus_v3_validation.json)及[来源调研](medical_corpus_v3_research.md)。本轮没有运行嵌入模型／付费 API 或读取 MIRAGE 测试内容。

## 执行节点

| 节点 | 工作 | 状态 |
| --- | --- | --- |
| 本轮数据准备 | 核验来源、使用条件、覆盖和资源，批量接入医学主语料并固定版本 | v3 主检索输入已交付并验证；NIH 原文因 403 未接入，用药／多模态专项题尚未完成 |
| 新数据版本固定后 | 用已有检索／评测程序建立新版本向量基线，完成 BM25 和 RRF 的正式对照 | 不以 CT 小库上先完成 BM25／RRF 为前置条件 |
| 后续检索改进 | 在同一固定版本上比较重排、改写、证据核验及有限补查 | 不同时更换数据和算法再归因收益 |

扩充资料按批次准备与验证，不以逐条加卡安排用户重做 B0。当前 238 条 CT 证据及 32 道开发题保留为回归与错误对照，主要方法比较迁移到扩充后的固定数据版本。

需要如实区分：已有代码不因扩库而重写；新增正文要编码，BM25 的词频／文档频率等统计要更新，索引和评测需要重建或重跑。当前未实现增量缓存，不能承诺扩充只换文件路径而没有计算成本。冻结主要数据版本后再做方法实验，是减少重复计算和重复对照的安排。

## 各数据集职责与仍待补项

1. 广泛医学检索语料：v3 已冻结，是自定义 PMC＋DailyMed＋CT 设置，不等同原始 MedRAG 全量语料；规模不证明所有 MIRAGE 问题已有答案。纯 384 维 float32 向量预计 1.121 GiB，不含模型、Python 对象、Qdrant payload 或 HNSW。实际编码和索引速度／内存仍需测量。
2. 专项产品验证材料：已研究并拟定美国 HIV ARV／他汀相互作用，已有相关产品 SPL 和论文，NIH 本机网页与官方 PDF 均 403，未算成功入库。专用参考题、独立复核和跨来源验证仍待完成。报告多模态配对材料按原任务准备，同一报告的多个版本不能计为多个独立病例。
3. 新数据版本：保留来源记录、原始快照、统一证据与位置、许可状态、质量隔离、题目划分和标注状态。扩充后更新向量及索引，用已有程序运行；不重新写检索和评分逻辑。

基准题获取、广泛医学语料、专项人工复核、多模态材料和最终模型对标分别报告完成状态。原 CT 小库和模型生成初标不替代其中任意一项。

助手按已有授权负责数据核验、采集与辅助整理；用户继续实现检索、评分、生成与 Agent 核心代码。正式全量模型调用前估算实际成本，下载成功不等于已经完成 7,663 题实验。OKF 仍留到完整数据扩充后再对照。
